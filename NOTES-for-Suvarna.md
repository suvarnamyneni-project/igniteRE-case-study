# Notes for Suvarna

This checklist is for you, not for the case study page. The live page uses only what is in the project document and its images. Where a process step is not documented, the page says so in a sentence and stops. Fill these in with real detail when you have it, then edit `index.html`. Do not add numbers, quotes, or timelines you do not have a source for.

## Add when you have the real detail

1. **Research.** How the personas and the journey were made: method, who took part, how many, when, and any quotes you are willing to publish. The page says the file does not describe the research.
2. **Testing.** Usability tests, critique, or analytics behind the work. Nothing in the file describes a test.
3. **The 40% / 30% / 25% figures.** The result paragraph states them. It does not show how they were measured. If you have the source (what was compared, over what period), add one sentence in `#results`. If you cannot stand behind the method, consider softening that section before you send the link.
4. **Quick win.** The goal is named. The file does not say which pain point was chosen or what shipped because of it. `#problem` says that outright.
5. **Your reflection.** `#reflection` is a reading of the artifacts, plus a line that a personal postmortem is not in the file. Replace that with what you would redo, what you owned, and what constrained the work.
6. **Timeline, team, and employer.** Left out on purpose. The page does not name an employer. Add them yourself if you want them on a job application.
7. **Villa visual direction.** It is a signature experience on the framework diagram. The file never defines it. The caption on the diagram says so.
8. **Rachel & Team.** The card title is “Rachel & Team.” The file does not say who else is on the team.
9. **Calculators.** It is in the navigation, the architecture, and the journey (a short bar near the start). There is no calculators key screen in the file. Add one if you have it.
10. **Miro and early sketches.** Miro is listed with Sketch, Figma, and InVision. No board or sketch image is in the file. `#patterns` says that.
11. **SPOTLIGHT and IgniteRE.** The UI says SPOTLIGHT. The document and the award say IgniteRE. The page states both. A single sentence from you on how the names relate would help recruiters.
12. **InVision spelling.** The document spells it “Invision.” The page uses the product name InVision.
